# RosterPocket

A personal scheduling project for people balancing casual jobs, classes and other commitments.

The product focuses on evaluating proposed shifts against existing commitments and user-chosen transition buffers, then keeping planned and actual work hours distinct. Personal hour budgets are planning preferences, not determinations about employment conditions or visa compliance.

Schedules and employment labels can be sensitive. The initial scope excludes location tracking, payslip uploads, payroll calculations and automatic employer communication. Public examples and tests use synthetic schedules.

No usable application build or measured results are included yet.
